# 香火成神系统 0.24.0 改了什么

卡面 0.24.0，Schema 2.6.0。旧存档（2.2.0～2.5.0）照常迁移，不需要重开。

## 零、发版前修复（11-07 测试报告）

- **开局第一楼不再被「额外模型解析」盖成空白**：卡内 `[config_override]` 改回「随AI输出」（MVU 不再每轮多花一次 API）；开局补丁随提交记录存下来，每次 `VARIABLE_UPDATE_ENDED` 结算后只要第一楼还是「未开局」就原地补回。玩家自己在 MVU 设置里开着额外解析也不会再撞上。
- **归档人物三维恢复增长**：`protect()` 现在对带 `档案版本` 的人物收下 clock 结算后的 `信仰度 / 好感度 / 堕落值 / 当前权能 / 隐秘档案`（AI 乱写的那份早已被 `enforceDevotion` 还原），信仰度能过 60 升核心/狂热，好感乘区、堕落门槛全部接回；「归档到世界书」保存清单补上 `好感度 / 堕落值`，手动归档不再丢这两个值。
- **开局表单不再干等 3 分钟**：等待期间盯着酒馆的报错弹窗与 `GENERATION_STOPPED` / `GENERATION_ENDED`，API 一报错、生成一中断就立刻报失败并说明原因。
- Schema 没动（仍 2.6.0），老档不需要迁移。


## 一、世界书瘦身：删掉 12 条重复的 `[地域概要]`

- 异能都市的 6 条（`xhcs_entry_id 29~34`）与西幻的 6 条（`35~40`）和 `[地域] 当前地域详录` 首段逐字重复，直接从运行包里退役。
- `mergeBook` 升级时一并清掉存量聊天世界书里的 `[地域概要]`，不再占 Token。

## 二、角色卡版本号与简介自动同步

- 安装器 `write()` 现在同时写 `character_version` / `creatorcomment` / `data.character_version` / `data.creator_notes`，简介模板为「香火成神系统 vX.Y.Z。…」，**不含任何旧署名**。
- 启动器装好运行包后会静默同步当前角色卡的版本号与简介（前端角色对象同步刷新，列表上的 `0.16.x` 会立刻变成 `0.24.0`）。
- `inspect()` 增加「角色卡版本号或说明待同步」检查；运行包与安装包里已彻底搜不到任何旧署名。

## 三、三维养成：信仰提速 + 好感 + 堕落

| 维度 | 谁有 | 作用 |
| :-- | :-- | :-- |
| 信仰度 | 只有信徒 | 敬畏与虔诚；涨满升核心/狂热 |
| 好感度 | 所有人（未信仰 15 / 普通 30 / 核心 55 / 狂热 80） | 世俗好感与信任；信徒 ≥60 ×1.25、≥80 ×1.5 信仰乘区；非信徒 ≥60 极易入信，入信初始信仰 = 15 + 好感×0.35 |
| 堕落值 | 只有成年女性 | 羞耻防线与身心沉沦；≥60 可建隐秘档案、≥80 可用遥控套装 |

- 信仰提速：核心倍率 `0.5 → 1.0`；每日上限 普通 30→45、核心 15→35；起始 10→15；每档分数整体上调。
- 协同：信仰事件顺带涨好感（约 35%），"亲近"再顺带涨堕落；好感事件反向给信徒涨信仰；"温存"顺带涨堕落；欢愉道具目标 +15 堕落 / +6 好感；遥控套装门槛改为「成年女性 + 狂热或堕落≥80」。
- 在场保底：AI 楼层未报事件时，在场人物自动 +4 信仰（含好感乘区）、+3 好感，亲密场面 +6 堕落；负面事由不保底。
- 三轨各算各的：同一轮可同时提交信仰、好感、堕落三类事件，互不冲突；男性/未成年没有堕落值，AI 直改这三个字段会被守卫忽略。
- `0005` 每轮投影在场人物的好感/堕落数值与阶段（含「高好感易入信」提示），`0003`/`0024`/`0004` 写明三轨与事件格式。
- UI：人物详细资料与因果列表都有三色仪表盘——信仰（鎏金）、好感（绯粉）、堕落（魅紫），配阶段铭牌与心绪短评。

## 四、设置搬进状态栏 + 自动祈愿退役

- **删除旧卡的「自动祈愿」**：设置项与自动模型调用链一并移除，不再在消息落地后自发调用模型。
- 「祈愿簿（涩内容）」「随机来客（来客模式）」与「审查难度」从因果页搬进状态栏「设置」，保存时分别走 `wishOptions` / `setDifficulty`；祈愿簿与审查框只保留内容与记录。
