# 香火成神系统 0.22.0 改了什么

卡面 0.22.0，Schema 2.5.0。旧存档（2.5.0）照常读，不需要重开。

## 一、世界书不再越玩越厚：删掉 [人物摘要]，设定并回人物状态

- 建档 / 更新固定资料时不再新建 `[人物摘要] <id> · <rev>` 条目。以前每多一个人、每换一版资料就多一条 `enabled:true` 的常驻条目，聊到几十轮后世界书列表全是摘要。
- 同一个人只保留最新版 `[人物固定资料]`（`enabled:false`，只作因果页离线冷备）；`stage()` 写入新版后顺手 prune 掉旧版本与残留摘要。
- 性别、年龄、身份、外貌、性格、扮演摘要、与神关系这些静态设定改存在 `重要人物` 里；`0005` 只给**在场的最多六人**投影一行「人物设定：…；摘要：…」，离场的人根本不进提示词，零 Token。
- 升级时自动清理存量：`mergeBook` 会滤掉外源条目里的 `[人物摘要]`，HUD 载入人物档案时也会静默清一遍（幂等，没有就不写）。

## 二、神域范围：坐标距离说了算，AI 不能再口胡覆盖

- `rules.json` 新增 `domainGeography`：三大世界的 `unitKm`、起始神像、核心地标坐标（直接取自大地图 `ATLASES`，不会漂）、六阶段地貌覆盖详述。
- `clock.js` 新增 `domainCoverageView(data)`：按欧氏距离 × 1000 × unitKm 现算每个地标距神像多少米、是否被当前半径覆盖、需要晋升到哪一期；挂到 `view(data).domain`。
- `usePower` 增加坐标硬校验：当前场景（或目标所在位置）在半径外时，AI 就算写 `领域内: true` 也一律拦下，报「【神域范围硬约束】当前位置「青崖村」距神像约 3.35 公里，已超出铜像期神域半径（300 米），严禁在神域外施展「附身死物」！」。被拦下的用能不扣神力。
- 域外传音改为按真实位置核算：只有已建立联系的信徒付 2 点可传，其余直接拒绝。
- `0005` 每轮投影：当前半径（含阶段）、本阶段覆盖地貌、**已覆盖大地图坐标（带米数）**、**域外邻近坐标（带公里数与解锁阶段）**、当前场景神域判定；同时明确「除传音与铜像期起肉身出域外，一切权能必须在半径内」。
- `0003` 增加「神域范围硬边界」条目；`0004` 的神域营建不再要求 `x、y`，`schemaSource.js` 的 `BuildingSchema` 把 `x/y` 改成可选并默认 0（旧档照读）。

## 三、地图页重做 + 【✦ 神域】专属面板

- 删掉旧的本地网格神域图与按 `x/y` 钉的建筑图标（建筑没有坐标了）。
- 大世界舆图上：
  - 神像脚下画真实比例的神域覆盖圈 `.xhcs-domain-real-circle`（金像期 5 千米、玉像期 50 千米时能直接看到吞进神域的村落）；
  - 再画一圈无论怎么缩放都清晰的双层灵光光环与范围铭牌 `神域 · 半径 300米`；
  - 域内地标升级为翠金双环并标注 `✦域内`；点任意地标，详情栏顶部直接给「处于神域庇护内（距神像 0 米 · 当前神域半径 300 米）」或「位于神域范围外（距神像 3.35 公里 · 当前半径 300 米，需【金像期·5 千米】方可覆盖）」。
- 地图页顶部常驻神域速览条（阶段 / 半径 / 已覆盖地标数 / 营建数）与「进入神域详情 →」；点「✦ 神域」进入专属面板 `xhcs-domain-sanctum`：
  - 天象总览卡：阶段徽章、中心、大字半径、六阶扩张刻度轨（30米→50千米）、当前阶段地貌覆盖详述；
  - 距离雷达：左栏已覆盖地标（权能全开），右栏域外邻近地标（距离条、还差多少、需晋升至哪一期）；
  - 神域营建志：统计徽章 + 建筑卡片墙（类型印章、状态流光、安全标识、说明、建造者、住户 X/Y），无 `x/y`；
  - 域内法则 / 域外限制双栏。

## 四、MVU 变量折叠框正则（默认关闭）

- 新增正则 `[显示]美化 MVU 变量（折叠框）`（id `xhcs-mvu-variable-fold`），把 `<UpdateVariable>` 块收进默认折叠的 `<details class="xhcs-mvu-fold">`。默认 `disabled: true`：想逐轮看变量明细时，关掉「[显示]隐藏 MVU 更新块」、打开这条即可。
- 安装包给每条正则同时收录 `disabled: true/false` 两种形态的 canonical 哈希，`inspect` 改成查白名单：玩家自己切开关不再被误报「角色局部正则已被手动修改」。
- `merge` 升级时对显示类正则（`markdownOnly && !promptOnly`）保留玩家当前的开关，不强行重置。
- HUD 启动时幂等补齐：只热更新了运行包的存量角色卡缺这条正则时，会静默补进去（插在「隐藏 MVU 更新块」后面）。
