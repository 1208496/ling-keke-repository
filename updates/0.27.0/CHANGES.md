# 香火成神系统 0.27.0 改了什么

卡面 0.27.0，Schema 仍是 2.6.0（新字段 `民间`、`祈愿簿.自选常客` 都是宽松新增，老档直接升级，不用重开）。

## 一、每日香谱
每个剧情日，头一炷香烧成什么形由脚本定（同一天重 roll 不变）：平安香、贵人香、桃花香、口舌香、小人香……共 12 种，西幻没有焚香，换成看篝火的烟色（直烟、绕墩烟、火星上天、矮火……12 种）。每种给当天判定通过线 −4 到 +5。状态栏「此刻」审查框下面的「民间」里能看到今天的香形和解法。

## 二、系统吐槽
有判定的那一轮，当前系统人格（高冷御姐 / 沙雕萌妹 / 可靠执事 / 谜语古灵，各有口吻）会在结果揭晓处单独插一行【系统吐槽】，要么好笑要么涩（「涩的祈愿」开关关着时只写好笑）。
防重复：脚本记下最近说过的吐槽，每轮原样交还给 AI，请它换角度换句式；正文里再出现和以前太像的句子，状态栏直接不显示。

## 三、民间诨号
凡人当众议论神迹时，正文会冒出【诨号：外号｜来由】，旁边有「认下」按钮。点了才进诨号表（最多 8 个，按响度排）；再认一次同名外号响度上涨，每过一天自然回落一点。
- 最响的外号会告诉 AI：来上香的人多半冲着这名头来。
- 冲着外号来上香的人给香火：每天 +（前三个外号响度和 ÷10），上限随神像阶段（泥像 2，往后每阶 +2），已算进每日收入。
（对应玩家反馈「直播打了周家人，引来一大堆人上香，每日香火还是不变」。）

## 四、香客小传 + 记入常客
有名有姓的新面孔第一次出场，名字写成【香客：名字｜小传】，正文里显示成虚线名字，点开是一张小传卡，卡上有「记入常客」。记入后她会像常客一样隔几天再来、顺路来访（自选常客最多 12 位）。

## 五、常客心事三层、供品、气味、看别人
39 位常客每人补了：
- 心事三层：嘴上来求的（表）→ 入信后露出的真正想要的（里）→ 成了核心信徒才碰得到的那件事（底），按信仰等级逐层交给 AI；
- 一样惯常带来的供品和它的来历、一种神闻得到的气味；
- 对另几位常客的一句看法（她本人口吻），只在玩家也认识那几位时才交给 AI。
常客在场时（不只是来访那一轮）也会带上这些。

## 六、祈愿一次显灵
祈愿簿里应下的事有待演出时，底部出现「显灵：把应下的 N 件事一起发出去」，一次发送、一轮正文全部演完。

## 怎么测的
- 单测：香谱逐日变化与修正、诨号排序与慕名香火、吐槽回填、自选常客资料拼装、常客分层按信仰露出。
- 隔离测试酒馆：0.26.1 卡 → 0.27.0 升级完整性全绿；真点开局；一轮里同时出判定、诨号、香客三种标记，全部渲染、原文不外露；「认下」「记入常客」写入存档、按钮变已完成；民间面板显示香谱/外号/慕名；判定通过线 = 一般 70 + 新手期 10 + 香谱 3 = 83；应了祈愿后「显灵」一次发送、待演清零；重复吐槽被隐藏；AI 收到的提示里有香谱、最近吐槽、外号、常客供品/气味/心事。
