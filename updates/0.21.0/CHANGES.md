# 香火成神系统 0.21.0 改了什么

卡面 0.21.0，Schema 2.5.0。旧存档（2.4.0 / 2.5.0）照常读，不需要重开。

## 一、隐秘档案：每段 ≤ 30 字，只给成年女性

- 七个文本字段（亲密关系、口腔、乳房、小穴描述、小穴特质、后穴、秘密）一律**硬上限 30 个汉字**：生成提示词写成最高优先级的篇幅硬约束，落地时再按句读截断；兜底词条本身也压缩到 30 字以内，截断后不会和兜底对不上。
- **男性角色严禁拥有隐秘档案**：`canHaveDossier` 增加性别校验（性别为空或含「男」一律拒绝），资料弹窗不渲染面板、保存直接拒绝、历史上残留的 `隐秘档案` 会被清掉；每轮注入与 `0005` 状态投影同样按女性过滤，摘要每段截到 30 字。
- 旧的 200 字 / 95 字上限取消。

## 二、「归档人物资料」真正写进聊天世界书，隐秘档案随档输出

- 之前点「保存到当前聊天世界书」只写了一条 `enabled:false` 的内部 `[人物固定资料]`，长文归档还回流到「人物详细资料」弹窗。现在保存时统一调用 `writeCombinedCharacterWorldbook`：在当前聊天世界书写一条**启用的** `[角色归档] 姓名（id）`，正文依次是【日常扮演摘要】、【人物完整归档资料】、【隐秘档案】（该女性角色已生成时）。
- `[角色归档]` 不再被 `disableLegacy` 自动禁用；旧的独立 `[隐秘档案]` 条目在合并时清掉，避免重复注入。
- 「人物详细资料」里**删掉「完整归档」长文区块**；归档正文只存在世界书条目里。
- 修掉档案版本切换时把 `隐秘档案` 冲掉的 Bug：`stage()` 不再把它冻进固定资料，归档事务与 `distillCharacter` 都会保留 `隐秘档案` 和 `已归档世界书`。
- 隐秘档案面板移除失效的「隐秘建档」按钮，只剩「生成 / 更新」；生成或鉴赏之后，如果该角色已有 `[角色归档]`，会把最新隐秘档案刷进那条里。

## 三、遥控套装：50 积分，永久背包道具

- `lewd_toylink` 价格 18 → **50**，`permanent: true`、`limit: 1`、`evolve: 0`，文案去掉「60 剧情分钟后化回神力散去」。
- 买过一次就一直留在背包（数量恒为 1、标「永久持有」、**没有丢弃按钮**，`dropGood` 也直接拒绝）；再次购买提示「已在背包中（永久持有）」。
- 使用时不再扣背包数量；同一时间只绑一位在场狂热信徒（旧实例与旧演化记录先清掉），演化行为 `永久: true`，`到期分钟` 用远未来值，不随剧情时间消散；背包里「神力演化中」显示「穿戴中 · 永久」，随时可以在面板里收回。

## 四、「己身」置顶：肉身与神像的能力 / 力量状态

- `[data-view="self"]` 最上方新增 `[data-role="self-power"]`：顶部是**领域不死铁律**，下面两张卡分别是「神像本体（及领域内化身）战力对标」和「肉身 / 化身能力状态」（位格、当前状态、领域内实力、域外独立实力），底部可展开「泥像期 → 玉像期」完整对照天梯。
- `rules.json` 新增 `combatBenchmarks`（6 阶段 × 3 世界观），`clock.js` 的 `selfPowerView` 挂到 `view(data).selfPower`；`0005` 状态投影每轮注入当前阶段的领域内对标、不死法则、肉身位格与域外境界。
- 战力阶梯：领域内铜像碾炼气、银像碾筑基、金像碾金丹（可抗衡元婴）、玉像直接最强（碾化神及另两界最强），领域内肉身与神像同实力、战死当场重聚重生；域外肉身铜像=凡人、银像=炼气、金像=筑基、玉像=金丹～元婴且可凭肉身飞行（都市 / 西幻按各自等阶换算）。
- 世界书 `0024`（不死与重生铁律）、`0012`（荒古）、`0014`（平行地球）、`0015`（西元）的「领域内外表现」章节全部与上表同步；`0012` / `0014` / `0015` 从本次起纳入构建覆盖。

## 怎么测的

- 离线：`node test/*.mjs` 全绿（新增 `v021-features.mjs`：30 字上限与兜底、男性禁入、归档合并写入、遥控套装永久化、3 世界观 × 6 阶段战力对标；`dossier.mjs` 增加 6 条「模型吐近似 JSON 也能救回来」的断言）。
- 实机：SillyTavern 1.19.0 + 酒馆助手 4.12 + MVU，按 `REAL_TAVERN_TEST.md` 在副本上跑 `tools/e2e-021.mjs`，**42 项全过、控制台无香火成神报错**：
  - 运行包 0.21.0 / schema 2.5.0，聊天世界书仍是唯一一本 `香火更新_<hash>`，系统条目全部 `xhcs_release = 0.21.0`。
  - 己身最上方是 `self-power`：不死铁律 + 神像/领域内对战对标 + 肉身位格 + 域外境界；3 世界观 × 6 阶段都能取到对标文本。
  - 女核心信徒真模型生成隐秘档案：七个字段全部非空且 ≤ 30 字；面板上没有「隐秘建档」按钮。男性狂热信徒打开资料没有档案面板，之前塞进去的残留档案被清掉。
  - 「归档人物资料 → 保存到当前聊天世界书」：聊天世界书写出启用的 `[角色归档] 艾兰妮亚（first_visitor）`，正文含【日常扮演摘要】+【人物完整归档资料】+【隐秘档案】，旧的独立 `[隐秘档案]` 条目被清掉；`隐秘档案` 与 `已归档世界书` 字段都保留；人物详细资料里不再出现完整归档长文。
  - 遥控套装：货架 50 点、买后背包「永久持有」且无丢弃按钮、再买被拦「已在背包中（永久持有）」、使用时背包数量仍是 1、`dropGood` 被拒；一轮真正文后演化记录带目标且 `permanent: true`，剧情时间再推进 300 分钟仍在，卡片写「穿戴中 · 永久」。
- 测试中真实踩到并修掉的一处：真模型偶尔返回「差不多是 JSON」的文本（尾逗号、全角冒号/引号），0.20 的解析只有一次机会，于是面板直接弹「模型返回的不是合法 JSON」。现在 `parseGenerated` 先按原样解析、失败再做最小修补，并把解析失败也算作一次失败、带纠正提示重试；原始返回留在 `window.__xhcsLastDossierRaw` 方便排查。
