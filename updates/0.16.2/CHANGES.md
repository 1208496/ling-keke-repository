# 香火成神系统 0.16.2 改了什么

基于线上 0.16.1。还没有发布：`main` 和 `channel.json` 没动，玩家不会收到。

## 头像设置不了

图片其实存进去了，但玩家看不到：

- 「此刻」页的头像框只显示姓氏，从不读图。
- 资料页的头像按钮被隐藏，存完只刷新了这个隐藏按钮。
- 信众列表要等下一次重绘才更新。
- 头像按「姓名+年龄+性别」存，AI 后来补上性别，头像就丢了。

现在：

- 「此刻」、资料页、信众列表都显示头像，存完立刻一起刷新。
- 点「此刻」页的头像框能打开资料页，资料页里能直接看到和更换头像。
- 头像改按人物 ID 存，旧头像还能读到，再次保存时迁到新位置。

## 系统商城

权能不再出售，到对应阶段自动掌握，每次发动照常付费。旧档已付的钱不退，也不追收。

商城改卖三类东西：

- **物品：** 26 种，分布在六个阶段，名字随世界变，比如急救包、金创散、治疗药水。
- **一次性权能卡：** 9 种，只卖还没到手的权能，比晋升早一阶，比如一次性附身卡。发动时免费，用完就没。
- **AI 定制商品：** 正文遇到货架解决不了的难题时，AI 可以上架，比如「镇水石符」。

货架规则：

- 每个剧情日换一次，也会跟着处境变。受伤、危险、不安、邪祟、待查、冷清、营建都会触发「应急」商品。
- 物品每天限购 3 件，权能卡和定制商品限购 1 件。

使用流程：买入进背包，点「使用」时可以指定在场人物，下一轮回复生效，生效前可以撤回。重 roll 会把物品效果重新发给 AI。

AI 定制的限制：

- 每个剧情日最多上架 2 件，价格由脚本按阶段限幅。
- 不能卖积分、信徒、晋升、永久能力或现有权能。
- AI 改不了余额和背包。

## 老存档启动失败

系统人格是旧名「沙雕萝莉」的存档，在 0.16.1 会整张卡启动失败，报「迁移改变已有值 /系统/人格」。原因是 Schema 改了旧值，而迁移检查不许改。

现在去掉了 Schema 里的这个转换，提示词和开局页本来就会把旧名显示成新名。

## 版本

- 卡片 0.16.2，Schema 2.1.0，有 2.0.0 → 2.1.0 的迁移边，操作为空。
- 正则没动，所以旧卡可以直接热更。
- 只改了 clock、hud 两个模块，Schema，以及世界书第 1、3、4、5、24 条。

## 测试

在独立的 SillyTavern 1.18.0 + 酒馆助手 4.11.3 里跑真卡，AI 用的是假接口，回复是写死的。

| 测试 | 结果 |
|---|---|
| 0.16.1 老存档热更到 0.16.2 | 通过，神力、阶段、人物都在 |
| 「沙雕萝莉」老存档 | 0.16.1 启动失败，0.16.2 正常 |
| 完整更新器写卡文件、刷新 | 通过，状态 activated |
| 买、用、撤回、重 roll | 通过，真实提示词里有物品效果 |
| 权能卡 | 免费发动一次，用完再发动被拒 |
| 普通权能 | 正常扣费 |
| AI 上架 | 报价 999999 被压到 400，「神力礼包」被拒 |
| AI 偷改余额和背包 | 无效 |
| 头像 | 三处实时显示，旧头像能读到 |
| 手机 390 宽 | 商城无横向溢出 |

## 没测、没改

- 没接真实模型，AI 会不会合理使用「上架」和物品效果，要真玩才知道。
- 价格是按各阶段任务奖励估的，没有经过真玩调平。
- 卡片备注写的运行环境是 SillyTavern 1.19.0，测试用的是 1.18.0。
- 这些旧问题没改：第一个聊天升级失败后整页要刷新才能恢复；玩家手改过世界书的聊天，升级后不能生成；旧版聊天世界书不会自动删除。
