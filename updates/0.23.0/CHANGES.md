# 香火成神系统 0.23.0 改了什么

卡面 0.23.0，Schema 2.5.0。旧存档照常读，不需要重开。

## 一、双重领域：内圈绝对无敌 + 外圈神力领域

| 阶段 | 内圈·绝对无敌领域 | 外圈·神力领域 |
| :-- | --: | --: |
| 泥像期 | 10 米 | 100 米 |
| 石像期 | 50 米 | 500 米 |
| 铜像期 | 100 米 | 1 千米 |
| 银像期 | 1 千米 | 10 千米 |
| 金像期 | 5 千米 | 500 千米 |
| 玉像期 | 50 千米 | 全大陆 |

- **内圈**：不管何人、何种境界踏入，一律被 USER 无视段位绝对碾压；神像与化身绝对不死、全部权能可用。
- **外圈**：同样绝对不死（肉身战死即刻重生）、全部已解锁权能可用，正面战力按当前阶段对标（铜像碾压炼气、银像碾压筑基、金像碾压金丹并抗衡元婴、玉像碾压化神）。
- **神力领域之外**：严禁施展领域权能，仅限对已建立联系的信徒付费传音（2 点/次）；铜像期起化身按「域外肉身境界」独立行动，肉身损毁则回归神像休整重聚。

落地位置：
- `rules.json`：`stages` 新增 `invincibleRadius/invincibleLabel/powerRadius/powerLabel/continentWide`；`combatBenchmarks` 六阶重写（`invincibleRule`、双圈 `domainRadius`、三界对标、域外肉身）；`domainGeography` 收录整张大地图全部地标，`stageScopes` 按三层现算现写。
- `clock.js`：`domainCoverageView` 输出 `invincibleMeters/powerMeters/invinciblePlaces/powerOnlyPlaces/outside/sceneZone`（`radiusMeters` 兼容指向外圈神力领域）；`usePower` 的边界与规模上限都按【神力领域】判定，拦截文案写明「超出X期神力领域半径（Y米）」；`syncPowers` 同步写内圈半径、神力半径、神力范围；晋升播报同时报双圈扩张；`selfPowerView` 增加内圈/外圈与无敌法则。
- `0005` 每轮投影：双重领域（内圈/外圈标签）、本阶段三层覆盖地貌、【内圈·绝对无敌领域内】地标、【外圈·神力领域内】地标、【神力领域外】邻近地标（带公里数与解锁阶段）、当前场景三层裁定。列表按条数截断，不会把整张地图塞进提示词。
- `0003`/`0024`/`0012`/`0014`/`0015`：不死与战力章节全部改成双重领域口径。
- HUD：顶部概览卡显示「神力 X」+「无敌 Y · 中心」；段位弹窗、己身页显示双半径与无敌法则；大地图画内圈赤金环 + 外圈翠青环与双圈铭牌，地标分「★无敌 / ✦神力」；神域志改成双圈总览 + 三栏雷达（无敌 / 神力 / 领域外）+ 三列法则。

## 二、MVU 黄字警告根治

- `schemaSource.js` 新增 `clipOpt / clipReq / clampIntOpt / cappedArray`：超长文本自动截断、越界数字自动钳位、超量数组自动截断，**不再让整楼变量更新报错**。
- `SystemEventSchema` 重写：`事由` 放宽到 120 字（`判定` 的长事由不再撞 `.max(10)`）；`作用半径` 钳到 1–50000000（适配 500 千米/全大陆）；`持续分钟` 钳到 1–10080；`数量` 钳到 1–999；未知事件类型收敛为「判定」；空 `事件ID` 兜底为 `auto-event`。
- `临时效果`(12)、`当前权能`(8)、`支线`(3)、`定制货架`(6)、`已知地点`(30)、`系统事件`(24) 全部改成 `cappedArray`，多塞几项只截断不报错。

## 三、商城道具：必进正文 + 免失败判定 + 输入框联动

- 新增 `shopItemBriefing(data)`，作为 `depth:0` 注入的第一块：列清本轮已激活道具的效果，并写明「商城道具效果 100% 必定完全兑现，严禁掷失败骰子、严禁写成不攻自破」。`fateBriefing` 同时追加免失败豁免。
- 待生效道具改为按楼层核销（`PendingGoodSchema` 新增 `楼层`）：用户楼层（floor === userFloor）绝不清空，只有 AI 楼层结算完才移除，保证道具 100% 活到正文写完。
- 背包点「使用」后会把 `（使用道具：名称）` 同步进输入框并提示；直接在输入框打「使用撒豆成兵符」也会被 `GENERATION_STARTED` 的 `autoUseFromText` 自动匹配背包道具并走正规生效通道。
- 商城战斗/防护道具补齐三界境界对标与保底：撒豆成兵符（800）召十二尊筑基圆满～半步金丹金甲力士、护心镜符/替劫纸人/天石敢当/天兵借道令等全部写明「必定100%生效」与对应境界。

## 四、支线奖励去重

- `clock.js` 新增 `cleanQuestRewardNote`：剔掉「奖励150点神力」「（一次性任务奖励）」这类复述，存量与新增任务在加载/结算时都清洗；`sideQuestBriefing` 要求 `奖励说明` 留空。
- HUD `appendTask` 渲染前同样清洗，面板不再出现「150点神力 · 奖励150点神力」。

## 五、商城批量购买

- `buyGood` 支持 `{ id, count }`：按今日剩余额度与神力上限自动收敛数量，一次扣总价、一次进包 N 件；权能卡/永久道具/限购 1 件仍强制单买。
- 商城卡片新增「− 1 ＋ / 最大 N」步进器，购买按钮实时显示 `购买 ×N（总价）`，确认框写明总价；`perform('buyGood', { id, count })` 全链路打通。
