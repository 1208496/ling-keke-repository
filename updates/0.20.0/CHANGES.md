# 香火成神系统 0.20.0 改了什么

卡面 0.20.0，Schema 2.5.0。旧存档（2.4.0）在切换聊天时按固定的一条边迁移；人物身上的新字段由结算兜底，迁移只做固定路径。

## 一、世界书不再越升越多

- 以前每升一版就新建一本 `香火更新_<命名空间>_<版本>`，旧的永远留在世界书列表里。现在书名固定成 `香火更新_<命名空间>`，升级就是**在原书里原位覆盖**。
- 系统条目（`xhcs_project` 归属本卡的那些）一律以本版为准覆盖；**外源条目原样保留**——`[角色归档]`、`[在场资料]`、这次新增的 `[隐秘档案]` 都不会被冲掉。
- 旧版里「本聊天世界书有手工修改，已保留旧版，未覆盖」的那道拦截去掉了：它原本会让每次升级都得另起一本。
- 提交成功后自动清理同一命名空间的历史版本世界书；只热更新了运行包、没换底座的存档，由 `clock.js` 启动时再兜一次（幂等）。
- 玩家自己开关过的世界观条目，覆盖时保留开关状态，正文一律用新版。

## 二、核心 / 狂热的「隐秘档案」

- 成年（≥18）且是**核心或狂热**的信徒，人物详情里多一块「隐秘档案」；其他人和未成年人不显示入口。
- **完全手动**：点「生成」→ 选档（随机抽取按概率，或指定 17 档之一）→ 静默生成 → 建档落变量。AI 每轮自动写私密状态的规则撤掉了。
- 17 档评级：D / C / B / A / S / 珍宝S / 神话S，以及 10 种神话 SSS 名器；每档都带硬约束（D–B 档禁止主动吮吸、锁死、喷潮之类的越级词，命中就回退到该档的写实文案）。
- **点击鉴赏**：评级默认藏起来，点了才跑老虎机（48～55 步、38ms 减速到 300ms），停在目标档；神话档会有庆祝动效。
- **隐秘建档**：一键写进聊天世界书 `[隐秘档案] 姓名（ID）`，条目是关键词触发的，只有提到她的时候才进提示词。
- **AI 改不动**：变量守卫把 `隐秘档案` 当脚本专属字段，模型补丁写到 `/重要人物/ID/隐秘档案` 直接忽略；资料块写回时也不会把它冻进资料版本或冲掉。
- 旧存档里的 `私密状态` / `私密档案` 会在下一次结算时一次性并进 `隐秘档案`（秘密、乳房、小穴、后穴有内容才搬，没写过的不编造）。
- 在场且有档案的信徒，每轮注入一段【隐秘档案·只读】摘要；投影里也带评级与隐秘心思，写明「只读，不要改」。

## 三、涩涩货架的遥控套装（仅限在场狂热信徒）

- 新增 `lewd_toylink`：古代修仙叫「阴阳同心遥感套装」、异能都市叫「TOY·LINK 遥控套装」、西幻叫「魔导共鸣遥控套装」，18 点神力，60 剧情分钟。
- **前后端双校验**：背包里的下拉框只列在场的**狂热**信徒（写成「涂山渺渺（狂热）」）；一个都没有时下拉框禁用、使用按钮置灰。后端 `useGood` 同样校验：不是在场狂热信徒直接拒绝。
- 内嵌 TOY·LINK v1.11.0 适配版：悬浮球 + 手机样式遥控器（九种波形 / 频率 / 强度 / 限时），状态同步进提示词。
  - 目标姓名绑定到当前确定的狂热信徒，不再拿角色卡名当目标，也不再允许切「作用对象」。
  - 自更新关掉了，也不会自己建世界书。
  - 生命周期跟着「神力演化中」走：使用后自动弹出一次遥控器，丙己身页的演化卡片上有「打开遥控器」；收回或到期自动停止并隐藏。

## 四、数据和兼容

- `重要人物` 多一个**可选**（但受保护）的 `隐秘档案`：`已生成 / 已鉴赏 / 更新时间 / 亲密关系 / 口腔 / 乳房 / 小穴评级 / 小穴描述 / 小穴特质 / 后穴 / 秘密`。没有的人身上不会长出这个字段。
- `商城.待生效` 条目多 `对象ID`、`商品ID`；`商城.演化` 条目多 `对象ID`、`商品ID`，遥控器靠它认目标。
- 守卫：`隐秘档案` 进忽略名单；`信徒培养` 等脚本字段规则不变。
- 运行包多了两个模块：`secret-dossier`（纯算法，无 DOM）和 `toylink`（遥控器）。引导脚本的模块校验按版本放行（0.20.0 起要八个）。
- 世界书：`[mvu_update]` 把「每轮写私密状态」改成「隐秘档案只读」；`[系统] 任务、积分…边界` 补了隐秘档案与遥控套装的边界；`[系统] 当前状态投影` 补了隐秘档案与遥控套装两段。

## 怎么测的

Node 断言 **491 条全绿**（含 `worldbook.mjs` 20 条、`dossier.mjs` 88 条、`toylink.mjs` 36 条、`v020-features.mjs` 26 条；其余 13 个文件是 0.19 的回归）。

- `worldbook.mjs`：用手工改过的旧书跑真实的 `mergeBook` / `installChat`，断言不抛错、系统条目覆盖、外源条目保留、开关状态保留、书名固定、旧版本书被删、第二次升级原位覆盖不新增。
- `dossier.mjs`：17 档权重与边界、档位硬约束、越级词回退、normalize 的优先级链、JSON 解析的五种脏回复、证据采集、世界书条目正文。
- `toylink.mjs`：DOM 桩里跑模块本体，没目标时不显示、设了目标后状态文本带名字、停止后收干净、不联网、不碰世界书。
- `v020-features.mjs`：守卫挡下 AI 写隐秘档案、旧字段迁移、注入只读摘要、遥控套装对核心/未信仰/不在场/没选人的四种拒绝、在场名单带等级、演化记录带商品与目标。

## 没测

- 老虎机动画与庆祝动效没有截图比对，只验证了逻辑分支（HUD 里那部分只能实机看）。
- `generateRaw` 的静默生成在实机上只跑了一遍（耗时与一次正文生成相当）。
- 跨界货架、觉醒、信仰度这些 0.19 的功能按原样回归，没有重新调手感。
