# 香火成神系统 0.16.4 改了什么

在 0.16.3 上改了三件事，都来自凌老师的实测反馈。卡面和数据结构（Schema 2.1.0）不变。

## 天命判定默认收起

「此刻」页只留一行小字「审查：标准」，点开才看判定记录和切换难度。信徒增长被退回时，提醒一直显示，不用点开。

## 玩家写下的结果不再算数

以前玩家写「我施展异象把人吓跑了」，骰子判失败，正文仍然写成功。现在提示词明确：玩家决定自己做什么，结果归世界和本轮判定。动作照写，效果看骰子，失败就写没做成。

用真实模型（Gemini flash-lite）做的对比，同一输入每种各跑 3 次：

| 情况 | 旧提示词 | 新提示词 |
|---|---|---|
| 骰子失败，玩家写「把追兵吓跑了」 | 3 次都写成吓跑 | 3 次都写成没吓跑 |
| 骰子成功，玩家写「把追兵吓跑了」 | 3 次都写成吓跑 | 3 次都写成吓跑 |
| 骰子失败，玩家写「她立刻信了我」 | 3 次都没入信 | 3 次都没入信 |

样本小，只测了这一个模型。换模型、换预设可能不一样，提示词只能减少这种情况，不能杜绝。

## 新增神力账本

在「权柄」页，折叠标题显示累计收入和支出，点开能看：

- 起始积分，以及信众日收益、跪拜、任务、晋升、商城、权能各自的累计。
- 最近 12 笔变动：日期、类别、来源、金额和余额，比如「跪拜 · 艾莉丝 +5」「任务 · 修好水井 +40」。

分类累计从账本启用时一直在记，所以老存档也能看到。老存档已有的流水没有来源说明，只显示类别；账本最多保留最近 64 笔。

## 测试

在独立的 SillyTavern 1.18.0 + 酒馆助手 4.11.3 里跑真卡。除上面的对比外，AI 都是写死回复的假接口。

| 测试 | 结果 |
|---|---|
| 已上线的 0.16.3 卡用完整更新器升级 | 通过，状态 activated |
| 0.16.1 老存档热更 | 通过 |
| 判定栏默认收起，被退回的提醒可见 | 通过 |
| 账本各来源记账 | 通过，起始 + 收入 - 支出 = 余额 |
| 手机 390 宽 | 账本无横向溢出 |

## 没改

- 除信徒增长外，其他判定仍然只靠提示词，脚本判断不了正文是否照做。
- 模型有时不提交行动判定事件。判定记录会少一条，不影响正文结果。
- 0.16.2、0.16.3 说明里列的旧问题没动。
