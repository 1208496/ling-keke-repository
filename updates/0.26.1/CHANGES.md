# 香火成神系统 0.26.1 改了什么

卡面 0.26.1，Schema 仍是 2.6.0，老档直接升级，不用重开。这一版在 0.26.0 成品包上打补丁，专治 Discord 里集中反馈的几件事。

## 一、判定不再「开局全是大失败」（P0）

玩家反馈：开局掷出来不是 90 就是 100、旁观也大失败、新手教程都过不去。骰子本身是均匀的，问题在通过线太低，加上 98 以上一律大失败，AI 又常把难度往高里定。

- 通过线（标准档）：容易 80→**90**，一般 55→**70**，困难 30→**50**，极难 10→**25**。「从容 / 严苛」照旧 ±。
- **开局第一个剧情日是新手期**，通过线再 +10。
- 大失败只在掷出 **99、100** 且没过线时出现；大成功放宽到 **1–5**。
- 提示 AI 哪些情况**不判定**：USER 旁观、隐身、闲聊、观察、日常相处；使用商城道具；在内圈【绝对无敌领域】里亲自出手对付闯入者（必成）。拿不准定「一般」，不许为了制造波折往高里定。天命注入、【合理性审查】条目和判定事件说明三处同步。
- 状态栏审查摘要直接写出骰子：`最近：事由（一般）1d100＝28，≤80算成 · 干净成功`。

## 二、「固定档案缺失，未覆盖旧引用」（P0）

人物固定资料的查找钥匙里带着聊天 ID。玩家一改聊天名，旧档案全都对不上，AI 再给这个人写资料块时整轮归档报错停掉。

- 查档案时，按「聊天+人物+版本号」找不到，就按「人物+版本号」兜底找回（clock 与 hud 两处）。
- 真找不到旧档案时不再抛错，按这次的资料重新建档，控制台留一条提示。

## 三、状态栏挤成一竖条（P1）

状态栏根节点有 `container-type:inline-size`，这会让它的「内容宽度」算作 0。外层按内容收缩时（部分主题、`inline-block` / `float` / `fit-content` 的消息框），状态栏塌成只剩内边距的 42px 竖条。现在加了保底宽度 `min-width:min(560px, 100vw - 96px)`。实测 390px 手机：旧版 42px，新版 294px；普通、气泡、文档三种显示模式都正常。

## 四、玩家改过的世界书不再被升级冲掉（P1）

- 文风、世界观这类设定条目（`[mvu_plot][文风]`、`[世界]`、`[地域]`、`[实力]`、`[开局]`、`[人物]`、`[种族]`）玩家亲手改过，升级时**保留玩家的版本**；系统规则条目照旧以新版为准。想要回官方文本：删掉那条，下次进聊天会自动补回。
- 玩家「复制」出来的系统条目（带着同一个稳定 ID）以前升级时会被吞掉，现在当成玩家自己的条目留下。
- 玩家自建的条目照旧原样保留。
- 判断「改过」用的是条目里记的内容指纹，换行 CRLF/LF 差异不算改过。
